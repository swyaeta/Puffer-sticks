# Puffy-notes

Puffy-notes is a lightweight desktop sticky-notes application built with Python and Tkinter. It provides a simple space for users to create and write notes through a colourful interface inspired by the Powerpuff Girls.

## Features

- Create and write custom notes.
- Character-inspired interface featuring Blossom, Bubbles and Buttercup.
- Simple and user-friendly design.
- Lightweight desktop application.

## Technologies Used

- Python
- Tkinter
- Pillow (PIL)

## Installation

1. Visit the [Releases](../../releases) section.
2. Download `Puffy-notes-Windows.zip`.
3. Extract the ZIP file.
4. Run `Puffy-notes.exe`.
